# 🎬 Cine & Books

### Películas que te entretienen. Libros que te transforman.

## 📌 Descripción del proyecto

**Cine & Books** es una landing page diseñada para reunir y presentar una selección de películas de acción, películas de comedia y libros de superación personal en un solo lugar.

El objetivo es ofrecer una experiencia visual moderna, intuitiva y atractiva, que permita explorar fácilmente cada categoría y descubrir nuevas opciones de entretenimiento y crecimiento personal.

El proyecto se desarrolla como práctica de diseño web y desarrollo frontend, aplicando HTML y CSS para crear una interfaz responsive con animaciones y efectos visuales.

## 📚 Contenido

La plataforma contará con 18 recomendaciones organizadas en tres categorías.

### 💥 Películas de acción

Una selección de cuatro películas para quienes disfrutan de la adrenalina, las aventuras y las escenas espectaculares.

- 4 películas de acción.

### 😂 Películas de comedia

Seis opciones para disfrutar de historias divertidas, personajes memorables y momentos llenos de humor.

- 6 películas de comedia.

### 🚀 Libros de superación personal

Ocho libros seleccionados para explorar temas como el desarrollo personal, los hábitos, la productividad, la mentalidad y el crecimiento profesional.

- 8 libros de superación personal.

## ✨ Características del diseño

- **Diseño responsive:** adaptación a computadoras, tablets y dispositivos móviles.
- **Interfaz moderna:** composición visual limpia, organizada y fácil de navegar.
- **Paleta de colores:** negro, verde y azul para una identidad visual tecnológica y contemporánea.
- **Efectos hover:** interacciones visuales al pasar el cursor sobre tarjetas y elementos.
- **Animaciones CSS:** movimientos y transiciones sutiles para enriquecer la experiencia.
- **Organización por categorías:** acceso sencillo a películas de acción, comedia y libros.
- **Tarjetas visuales:** espacio para imágenes, títulos y descripciones de cada recomendación.

## 🛠️ Tecnologías

- **HTML5:** estructura semántica de la landing page.
- **CSS3:** estilos, colores, tipografía, animaciones y transiciones.
- **Flexbox:** alineación y distribución de elementos.
- **CSS Grid:** organización de las tarjetas en filas y columnas.
- **Media Queries:** adaptación del diseño a distintos tamaños de pantalla.
- **Git y GitHub:** control de versiones y publicación del código.

## 🎨 Identidad visual

La propuesta visual utiliza una paleta oscura con acentos verdes y azules.

| Color | Aplicación |
|---|---|
| Negro | Fondo principal y secciones |
| Verde | Acentos, botones y elementos destacados |
| Azul | Enlaces, detalles y elementos interactivos |
| Blanco o gris claro | Textos y contenido informativo |

La interfaz busca mantener un buen contraste, una jerarquía visual clara y una navegación cómoda.

## 📱 Diseño responsive

La distribución de los elementos se adaptará según el dispositivo:

- **Escritorio:** tarjetas organizadas en varias columnas.
- **Tablet:** reducción del número de columnas para conservar la legibilidad.
- **Móvil:** disposición simplificada, con tarjetas adaptadas al ancho disponible.

## 🚀 Cómo ejecutar el proyecto

1. Clona el repositorio o descarga los archivos.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre el archivo `index.html` en tu navegador.
4. Opcionalmente, utiliza la extensión Live Server para visualizar los cambios durante el desarrollo.
