# Cine & Books

Landing page responsive para descubrir películas de acción, comedia y libros de superación personal.

## Características

- 4 películas de acción y 6 de comedia.
- 8 libros de superación personal.
- Diseño oscuro con acentos verdes y azules.
- CSS Grid, Flexbox, variables CSS y media queries.
- Animaciones, transiciones y efectos hover.
- Menú móvil sin JavaScript.
- Accesibilidad básica y preferencia de movimiento reducido.

## Tecnologías

HTML5 y CSS3.

## Cómo ejecutar

Abre `index.html` en tu navegador o usa la extensión Live Server de Visual Studio Code.

## Nota sobre imágenes

Las diez ilustraciones de películas están guardadas localmente en la carpeta `images/`, por lo que no dependen de URLs externas para mostrarse. Son ilustraciones originales inspiradas en géneros y escenas cinematográficas, no pósteres oficiales.
 Los diseños de portadas de libros son creados con CSS como recurso visual de práctica y no son imágenes oficiales de las ediciones.

## Objetivo

Proyecto educativo para practicar estructura semántica, diseño responsive y fundamentos de CSS.


### Actualización de películas
- 20 películas distribuidas en las pestañas Acción y Comedia.
- Cada pestaña muestra cuatro películas inicialmente y el botón **Ver más películas** revela hasta cuatro adicionales por clic.
- Cada tarjeta incluye una descripción breve.
